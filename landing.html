Cara Kerja

3 langkah. Beneran.

Tidak ada konfigurasi rumit. Tidak ada driver aneh. Just works.

🗂️
Drop File
Drag & drop file apapun ke aplikasi. Bisa satu, bisa puluhan sekaligus.
🖨️
Pilih Printer
Printer terdeteksi otomatis. Pilih yang kamu mau, atur salinan & halaman jika perlu.
▶
Klik Print
Semua file masuk ke printer satu per satu, silent, di background. Sambil ngopi.
Pipeline per Format
PDF ──► Ghostscript (mswinpr2) ──► 🖨 Printer
DOCX/XLS/PPTX ──► LibreOffice headless → PDF ──► 🖨 Printer
ODT/RTF/HTML ──► LibreOffice headless → PDF ──► 🖨 Printer
TXT ──► PowerShell Out-Printer ──► 🖨 Printer
PNG/JPG/BMP ──► .NET PrintDocument ──► 🖨 Printer
